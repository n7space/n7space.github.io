Cortex-M7 Board Support Packages

Driver API documentation for Microchip ARM Cortex-M7 platforms

This page provides API documentation for low-level drivers included in N7 Space Board Support Package for SAMV71Q21, SAMRH71F20 and SAMRH707F18 platforms. The drivers have been developed according to ECSS standards (ECSS-E-ST-40C, ECSS-Q-ST-80C) and are available with complete qualification data package (QDP). Documentation was generated from source code using Doxygen.

More information about the libraries can be found at bootloader.space.
