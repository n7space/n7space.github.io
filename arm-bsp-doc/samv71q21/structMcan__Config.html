◆ msgRamBaseAddress

uint32_t* Mcan_Config::msgRamBaseAddress

Base address of the message ram; only the upper 16 bits are used which shall be constant for the whole message RAM area.

This buffer must reside in memory fully accessible by DMA. On SAMV71 Rev.A and SAMRH707 there's a bug causing the DMA to be unable to access non-32bit values via AHBS, which makes it impossible to place the message RAM in TCM memories.
