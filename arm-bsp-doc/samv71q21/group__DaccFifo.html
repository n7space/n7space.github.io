SampleFifo initialization procedure, checks the boundaries of samples and initializes FIFO for usage with already filled buffer.

Should be called before first use of SampleFifo. Has linear computational complexity, due to boundary checking. For non-checking, constant complexity version, see Dacc_SampleFifo_initFilledUnsafe(). If you want to initialize SampleFifo using an empty buffer, see Dacc_SampleFifo_init().

Parameters
[in,out]fifoPointer to SampleFifo instance.
[in]bufferMemory block to be assigned to SampleFifo as it's storage area.
[in]bufferSizeAmount of elements currently stored in the buffer (NOT the size in bytes!).
Returns
true if the initialization was successful, false if an invalid sample exists in a buffer.

SampleFifo initialization procedure, initializes FIFO for usage with already filled buffer of samples.

Should be called before first use of SampleFifo. Does not perform boundary checks for samples - make sure they are between 0 and Dacc_Sample_Max, otherwise they will most likely be trimmed. For boundary-checking version, see Dacc_SampleFifo_initFilled(). If you want to initialize SampleFifo using an empty buffer, see Dacc_SampleFifo_init().

Parameters
[in,out]fifoPointer to SampleFifo instance.
[in]bufferMemory block to be assigned to SampleFifo as it's storage area.
[in]bufferSizeAmount of elements currently stored in the buffer (NOT the size in bytes!).
