 Performs blocking flash program operation. The programming is performed byte-by-byte so it can be used to write data across pages and sectors. The timeout is used as a total countdown during instruction execution and all write byte operations.
 
bool Qspi_overwriteSector (Qspi *const qspi, void *const address, const uint8_t *const data, const uint32_t len, uint32_t timeout, ErrorCode *const errCode)
 Performs blocking flash erase program operations for a single sector. The programming is performed byte-by-byte so it can be used to write data across pages.  Starts the non blocking flash program operation. The programming is performed as a single flash command and is limited to the data within one page. The timeout is used as a total countdown during instruction execution including sending the data to the flash device.
 
bool Qspi_prepareDmaWrite (Qspi *const qspi, const void *const address, const uint32_t len, uint32_t timeout, ErrorCode *const errCode)
