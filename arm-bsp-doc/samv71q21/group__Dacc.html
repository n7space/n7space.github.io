enum Dacc_ChannelOutputCurrent

Enumeration listing valid analog output current values. This setting also specifies maximum conversion rate.

Enumerator
Dacc_ChannelOutputCurrent_Low 

Output buffer is disabled, typically 10uA output, max 30uA, for low frequency signals only. Always set in Bypass mode.

Dacc_ChannelOutputCurrent_Normal 

Normal mode, typically 100uA output, max 400uA, max conversion rate 500ks/s.

Dacc_ChannelOutputCurrent_High 

High current mode, typically 200uA output, max 800uA, max conversion rate 1Ms/s. Always set in Max Speed mode.

Writes a single sample to DACC channel's FIFO.

Valid range of a sample value is between 0x000 (0) and 0xFFF (4095). Make sure that FIFO is not full using Dacc_waitUntilFifoIsNotFull() before calling this function. It's not possible to verify FIFO state without interrupts. If End of Conversion interrupt is enabled, you can check if the conversion is finished using Dacc_isConversionFinished() function. It's not possible to check if the conversion has finished without interrupts. This function does not enable any interrupts by itself.
