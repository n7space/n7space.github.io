void Nvic_relocateVectorTable ( const void *const  address)

Function used to change the address of the vector table in NVIC.

Function disables interrupts globally for vector address change, then re-enables them afterwards. This has potentially unwanted side effect of enabling interrupts even if they were disabled before. also see Nvic_relocateVectorTableUnsafe .

Parameters
[in]addressAddress of the new vector table.
