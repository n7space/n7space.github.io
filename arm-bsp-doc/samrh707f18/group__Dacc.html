◆ Dacc_writeSample()

bool Dacc_writeSample ( Dacc *const  dacc,
const Dacc_Sample  sample,
ErrorCode *const  error 
)

Writes a single sample to DACC channel's FIFO.

Valid range of a sample value is between 0x000 (0) and 0xFFF (4095). Make sure that FIFO is not full using Dacc_waitUntilFifoIsNotFull() before calling this function. It's not possible to verify FIFO state without interrupts. If End of Conversion interrupt is enabled, you can check if the conversion is finished using Dacc_isConversionFinished() function. It's not possible to check if the conversion has finished without interrupts. This function does not enable any interrupts by itself.

Parameters
[in,out]daccPointer to a structure representing DACC.
[in]sample16-bit sample with channel number provided.
[out]errorError code filled in case of a failure or invalid arguments, can be NULL.
Returns
True if writing was successful, false otherwise.

Writes samples from FIFO queue to DACC.

Valid range of samples values is between 0x000 (0) and 0xFFF (4095). Requires interrupts to be enabled in order to work. Automatically enables End of Conversion interrupt when called. Make sure that FIFO is not full by calling Dacc_waitUntilFifoIsNotFull() before this function.

Parameters

[in]samplesPointer to StructFifo containing DACC samples.
[in]handlerEnd-of-transfer handler with callback.
[out]errorError code filled in case of a failure or invalid arguments, can be NULL.
Returns
True if starting the transfer is successful, false otherwise.
