uint32_t Hemc_ChipSelectConfig::ncsRelativeBaseAddress

Base address of NCS memory area relative to 0x60000000.

Must be in range from 0x00000000 to 0x7FFFFFFF (0x00000000 to 0x3FFFFFFF if memory area shall be executable according to information in ARM DDI 0403E.e (ID021621) document). It is recommended to select base address as multiple of 0x10000000 to place the memory area in separate section according to Bus Matrix's sections division related to HEMC. Only 18 most significant bits of this value are actually taken into account for configuration.
