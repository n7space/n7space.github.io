Detailed Description

Auxiliary header for basic bit operations on registers.

Module representing fixed-size struct queue based on circular buffer.

Module defining error code type and reporting functions.

Module providing methods for handling various byte orders.

Module representing flag for monitoring concurrent access to data.

Module representing fixed-size byte queue based on circular buffer.

Module representing bytes collection with dynamic size but fixed capacity.

Should not be used directly, but as 'base class' for other queues (ensuring type safety).
