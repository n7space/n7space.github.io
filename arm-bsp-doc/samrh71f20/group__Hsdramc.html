enum Hsdramc_CommandMode

Enumeration listing HSDRAMC command modes.

Enumerator
Hsdramc_CommandMode_Normal 

SDRAM accesses are decoded normally.

Hsdramc_CommandMode_Nop 

"NOP" command is issued when SDRAM is accessed.

Hsdramc_CommandMode_AllBanksPrecharge 

"All Banks Precharge" command is issued when SDRAM is accessed.

Hsdramc_CommandMode_LoadModeReg 

"Load Mode Register" command is issued when SDRAM is accessed.

Hsdramc_CommandMode_AutoRefresh 

"Autorefresh" command is issued when SDRAM is accessed. "All Banks Precharge" command must be issued before this command is issued.

Hsdramc_CommandMode_ExtLoadModeReg 

"Extended Load Mode Register" command is issued when SDRAM is accessed.
